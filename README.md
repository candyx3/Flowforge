# Flowforge

**Build, connect, and run AI-powered workflows with ease.**

Flowforge is an AI workflow platform designed to help developers build applications powered by large language models (LLMs), connect different AI services, and create intelligent workflows through a visual interface.

## Features

- **Visual Workflow Builder** — Create workflows by connecting components.
- **AI Integration** — Work with LLMs and AI providers.
- **Custom Workflows** — Build workflows tailored to your use cases.
- **Extensible Architecture** — Add integrations and customize functionality.
- **Developer Friendly** — Built with a modular architecture for development and maintenance.
- **Open Source** — Explore the codebase and contribute to the project.

## Tech Stack

- TypeScript
- Node.js
- React
- pnpm Workspaces
- Turborepo

## Getting Started

### Prerequisites

Make sure you have the following installed:

- [Node.js](https://nodejs.org/)
- [pnpm](https://pnpm.io/)

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/candyx3/Flowforge.git
   ```

2. Navigate to the project directory:

   ```bash
   cd Flowforge
   ```

3. Install dependencies:

   ```bash
   pnpm install
   ```

4. Start the development environment:

   ```bash
   pnpm dev
   ```

### Build for Production

To build the project, run:

```bash
pnpm build
```
